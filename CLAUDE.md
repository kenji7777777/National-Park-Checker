# National Park Checker

- The app is a single file, `index.html` (React + Babel loaded from cdnjs).
- It is published with GitHub Pages from `index.html` on the `main` branch.
- When making changes, overwrite the existing `index.html` and push it to `main` so it goes live.
  Do not add a new HTML file with a different name.
- Reports to the user should be written in Japanese.
